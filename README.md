# Gridless

A survival, world-building, and economic management game set on an artificially constructed replica of Earth.

## Repo Structure

- `docs/` — Game design documents, story bible, system specs
- `src/` — Game code
- `data/` — Config files, balance data, item definitions, etc.
- `assets/` — Art, audio, and other binary assets

## Getting Started

See [`docs/game-overview.md`](docs/game-overview.md) for the current game design overview.
